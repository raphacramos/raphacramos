## Featured projects

### [Elite swimming ETL pipeline](https://github.com/raphacramos/TCC) (thesis)

Extracts 33 official World Aquatics PDF results books (Olympics 2012–2024, World Championships 2016–2025) into 105,582 split records from 1,258 athletes in 151 countries, loads them into PostgreSQL with data-validation tests, and uses K-Means, chi-square and ANOVA to find which pacing strategies win medals.

`Python` `pandas` `pdfplumber` `PostgreSQL` `SQLAlchemy` `scikit-learn` `SciPy`

### [World Cup 2026 score predictor](https://github.com/raphacramos/Preditor-de-Placares-da-Copa-2026)

Statistical model for predicting match scores: Dixon-Coles with dynamic Pi-Ratings, Bayesian shrinkage for teams with little data, a fatigue index from travel distance, rest days and temperature, 10,000-run Monte Carlo tournament simulation and expected-value optimization of picks.

`Python` `statistics` `Monte Carlo`

### [Job prospector](https://github.com/raphacramos/Prospector-de-Vagas)

CLI that collects job posts from GitHub Issues, Hacker News "Who is hiring?" and the Greenhouse, Lever and Ashby APIs, filters them, and tracks the application funnel and follow-ups in SQLite.

`Python` `SQLite` `REST APIs` `TypeScript`

### BINGO Telescope (private code)

International radio astronomy collaboration. Control software and real-time telemetry acquisition for the MiniHorn spectrometer: Clean Architecture, HDF5 storage and SDR hardware integration through GNU Radio.

`Python` `HDF5` `GNU Radio`
